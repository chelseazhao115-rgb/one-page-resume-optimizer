# Repository Workflow

After every modification to this Skill:

1. Preserve the existing Skill structure and formatting rules.
2. Run all relevant evaluation cases.
3. Update `evals/results.md`.
4. Update `CHANGELOG.md` when behavior changes.
5. Verify no private resume data is added.
6. Review `git diff`.
7. Commit with a descriptive conventional commit message.
8. Push to the configured GitHub remote.

A change is not finished until evaluation results are recorded.
